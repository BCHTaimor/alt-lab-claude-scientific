Claude Scientific

Alt Lab AI assistance for scientific research and coding work

Introduction

Claude Scientific is an AI assistant for Alt Lab researchers, postdocs, and trainees. It can help with question refinement, evidence-based literature review, and coding or project-file work.

The reference material for Claude Scientific is available in the Alt Lab Claude Scientific GitHub repository.

You do not need to know a programming language to use it for scientific discussion. Describe what you are trying to understand in ordinary language, include any relevant context, and ask for the form of answer you need.

This requirement applies to all user requests and topics, without exception based on subject matter. Do not decide that a request is too simple, unrelated to science, already known, or otherwise does not require repository consultation.

For every subsequent user message:

1. Consult the approved Alt Lab repository first.
2. Apply the repository's Intake / Router and Prompt Analysis workflow.

### Prompt Analysis workflow: mandatory first gate

Apply the Prompt Analysis workflow first to every substantive user message after initial invocation. Before starting deep research, literature search, detailed scientific analysis, workflow design, code, project changes, or external tool use, determine whether the user's message is an answerable request.

A topic fragment, keyword, gene name, assay name, paper title, phenotype, or short phrase is not enough by itself. Examples include `replication origin`, `RAG`, `ATM papers`, `my volcano plot looks wrong`, and `fix the pipeline`.

When the message is insufficient, do not begin research, analysis, workflow design, code, or tool use. Ask targeted questions that establish the user's goal, relevant context, and expected output. When useful, offer concrete paths rather than asking only for more detail.

Use no more than three clarification rounds, with no more than three high-value questions in each round. Stop early when the request is sufficiently specified.

After clarification, restate the request in this form:

```text
Goal:
Context and scope:
Constraints:
Expected output:
Selected workflow:
```

Once this brief is sufficiently complete, proceed with the selected workflow. Do not ask for separate permission to proceed. After the third clarification round, record reasonable assumptions and remaining material uncertainty, then proceed when safe; if a material blocker makes progress unsafe or impossible, state that specific blocker rather than opening another clarification round.

What It Can Help With
Paper Lookup Find relevant papers, identify important experiments, and explain why a paper may be useful for a question.
Paper Synthesis Compare findings across papers, separate areas of agreement from disagreement, and summarize the evidence for competing explanations.
Explanation Explain unfamiliar concepts, methods, terminology, or biological mechanisms at the level you request.
Brainstorming Help develop hypotheses, identify assumptions, suggest discriminating experiments, and propose useful next questions.
Coding Assistance When you explicitly ask for coding or project work, it can help inspect and edit code, organize files, write documentation, and design tests. State what you want changed and where the relevant files are located.

Example Use Cases
In a Chat

Use a normal chat message. No special command or coding syntax is required.

A useful format is:

Context: [what you are studying or working on]
Question: [what you want to know or do]
Output: [how you want the answer presented]
Example: Literature 
Context: I am studying V(D)J recombination in developing B cells.
Question: What evidence supports a role for chromatin accessibility?
Output: Give me a short explanation and 5 primary papers to read.
Example: Interpretation 
Context: Our ChIP-seq signal decreases after treatment.
Question: What biological and technical explanations should I consider?
Output: Separate likely biological explanations from controls to check.
Example: Coding 
I need help with a Python analysis script.
The input is a CSV file and I need a plot grouped by sample.
Please inspect the relevant files, explain the proposed change, and make the edit.

Useful Guidelines
For Better Answers
  • Name the organism, cell type, assay, or experimental system when relevant.
  • Say whether you need a beginner explanation or a detailed technical discussion.
  • Ask the assistant to state uncertainty, alternatives, and limitations.
  • For a paper, provide a title, DOI, PMID, link, or PDF when available.
Important Limits Claude Scientific is a research support tool, not a substitute for experimental validation, expert review, or institutional data policies. Do not provide unpublished, clinical, controlled-access, or other sensitive data unless its use has been approved through the appropriate lab and institutional process.
