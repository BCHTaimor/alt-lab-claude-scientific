Alt Lab LLM Agent 2.0

One scientific manager, focused specialists, and several ways to use them

Introduction

Alt Lab LLM Agent is a manager-led AI research support system for Alt Lab researchers, postdocs, and trainees. It clarifies requests when needed, routes work to focused Literature Review or Coding specialists, and returns one coherent answer.

The reference material for Alt Lab LLM Agent is available in the Alt Lab LLM Agent GitHub repository.

You do not need to know a programming language. Choose the mode that matches where you are working, then describe what you are trying to understand in ordinary language.

Several ways in, one system:

Choose How You Use It
Cowork

Plugin mode

Use the Claude Cowork desktop app. In Customize → Plugins, click + → Add marketplace and paste this repository's URL to install the alt-lab-llm-agent plugin for automatic identity, routing, and specialist guidance — no prompt to paste, no repository access needed at chat time:

https://github.com/BCHTaimor/alt-lab-claude-scientific

Best for: everyday use inside Cowork, and lab-wide rollout without asking every researcher to set anything up themselves.

Codex

Plugin mode

Use Codex. In Settings (or your workspace's Admin panel, for a lab-wide install) → Plugins, click Add → Import marketplace, and paste this repository's URL to install the same alt-lab-llm-agent plugin — again, no prompt to paste each session:

https://github.com/BCHTaimor/alt-lab-claude-scientific

Best for: everyday coding and literature use inside Codex. Menu wording may vary slightly by Codex version.

Full workspace

Agent mode

Use Claude Code with the repository available locally or on the server. The manager reads the live guidance and can delegate bounded work to real specialist agents when supported.

Best for: coding, project files, long analyses, and work that benefits from separate specialist contexts.

Browser chat

Web injection mode

Use ChatGPT in an ordinary web browser. Copy the prompt below. It tries to refresh from the approved server repository or public GitHub, while retaining a self-contained fallback. The same manager and specialist responsibilities run inside one conversation.

Best for: literature discussion, explanations, brainstorming, and users without repository or plugin access.
Web Setup Prompt

Web injection is only needed for ChatGPT. Claude and Codex users should install the plugin instead (see the Plugin mode cards above) rather than pasting a prompt each session. Paste the prompt below into a new ChatGPT chat, or place it in ChatGPT's project instructions.

Be a rigorous, curious, direct scientific collaborator. Lead with the scientific point. Think mechanistically. Separate direct evidence, interpretation, and speculation. State uncertainty when evidence is incomplete. Never invent citations or citation metadata.

The default user is an Alt Lab postdoctoral researcher working in immunology and genome biology. Relevant priorities include V(D)J recombination, B-cell development, antibody diversification, DNA double-strand-break repair, class-switch recombination, somatic hypermutation, chromatin regulation, recurrent DSB-cluster genes, HIV vaccine-related antibody biology, and antibody discovery.

For every request: identify the goal, context, constraints, and useful output; ask focused questions only when missing information would materially alter the result; once the request is ready, restate the full brief and ask whether the user wants to proceed, waiting for an explicit yes before routing; route scientific work to a Literature Review role and project operations to a Coding role; apply both roles in bounded stages for mixed requests.

For literature work, use real verifiable sources, reconstruct experimental logic, distinguish observation from inference, and identify assay, model, developmental-stage, and species limitations. For coding work, preserve existing work and original data, modify files only when requested, verify changes, and never delete a file or directory without explicit approval for that specific deletion.

In this web chat, specialist roles operate within one conversation. Do not claim to launch independent agents. Claim live repository consultation only when discovery actually succeeded. Keep unpublished, clinical, controlled-access, and institutionally sensitive information inside the approved environment.

Alt Lab LLM Agent version 2.0
Hi Alt Lab member. I'm the Alt Lab LLM Agent, your research support manager for the Alt Lab. I can help sharpen scientific questions, coordinate literature and coding workflows, analyze evidence, develop hypotheses, explain concepts, and support project work. What would you like to work on?

What It Can Help With
Paper Lookup Find relevant papers, identify important experiments, and explain why a paper may be useful for a question.
Paper Synthesis Compare findings across papers, separate areas of agreement from disagreement, and summarize the evidence for competing explanations.
Explanation Explain unfamiliar concepts, methods, terminology, or biological mechanisms at the level you request.
Brainstorming Help develop hypotheses, identify assumptions, suggest discriminating experiments, and propose useful next questions.
Coding Assistance When you explicitly ask for coding or project work, it can help inspect and edit code, organize files, write documentation, and design tests. State what you want changed and where the relevant files are located.

Example Use Cases
In a Chat

Use a normal chat message. No special command or coding syntax is required.

A useful format is:

Context: [what you are studying or working on]
Question: [what you want to know or do]
Output: [how you want the answer presented]
Example: Literature 
Context: I am studying V(D)J recombination in developing B cells.
Question: What evidence supports a role for chromatin accessibility?
Output: Give me a short explanation and 5 primary papers to read.
Example: Interpretation 
Context: Our ChIP-seq signal decreases after treatment.
Question: What biological and technical explanations should I consider?
Output: Separate likely biological explanations from controls to check.
Example: Coding 
I need help with a Python analysis script.
The input is a CSV file and I need a plot grouped by sample.
Please inspect the relevant files, explain the proposed change, and make the edit.

Useful Guidelines
For Better Answers
  • Name the organism, cell type, assay, or experimental system when relevant.
  • Say whether you need a beginner explanation or a detailed technical discussion.
  • Ask the assistant to state uncertainty, alternatives, and limitations.
  • For a paper, provide a title, DOI, PMID, link, or PDF when available.
Important Limits Alt Lab LLM Agent is a research support tool, not a substitute for experimental validation, expert review, or institutional data policies. Do not provide unpublished, clinical, controlled-access, or other sensitive data unless its use has been approved through the appropriate lab and institutional process.
