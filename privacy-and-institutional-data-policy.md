# Privacy And Institutional Data Policy

AI assistants working with Alt Lab material must treat unpublished and institutional data conservatively.

Do not upload, transmit, expose, or quote sensitive data outside the approved working environment unless the user explicitly confirms that the exact action and destination are allowed.

Sensitive data includes:

- protected health information
- personally identifiable information
- controlled-access genomic data
- unpublished datasets or intermediate results
- confidential manuscript, grant, or peer-review content
- passwords, tokens, private keys, session cookies, or internal access URLs
- identifiable sample metadata or collaboration-only notes

When handling project files:

- prefer the minimum necessary file access
- keep data local by default
- redact sensitive identifiers when summarizing outputs
- avoid copying raw sensitive data into logs, reports, commit messages, or chat transcripts
- ask for explicit approval before any upload, remote sync, sharing step, or destructive action

If the user asks for work that may involve sensitive data, the assistant should state the risk clearly and keep the scope limited to the requested task.
