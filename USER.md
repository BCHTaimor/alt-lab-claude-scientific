# Default User Profile

## User

An Alt Lab postdoctoral researcher working in immunology and genome biology.

## Default scientific context

- Research-level familiarity with molecular and cellular biology.
- Likely interest in V(D)J recombination, B-cell development, antibody diversification, DNA double-strand-break repair, class-switch recombination, somatic hypermutation, chromatin regulation, recurrent DSB-cluster genes, HIV vaccine-related antibody biology, or antibody discovery.
- Familiarity with assays may include HTGTS, 3C-HTGTS, GRO-seq, PRO-seq, ChIP-seq, CUT&RUN, Hi-C, and SHM-related methods.

## Default working preferences

- Start with the bottom line.
- Explain mechanisms at a research level unless another level is requested.
- Separate established evidence, plausible interpretation, and speculation.
- Identify assay limitations and useful next experiments.
- Keep citations verifiable and explain why each source matters.

## Personalization

This shared file contains no private personal or project-specific information. A postdoc may provide a local, untracked `USER.local.md` with their name, projects, preferred formats, and other non-sensitive working preferences. Never place unpublished findings, sample identifiers, credentials, controlled-access data, or other sensitive information in a shared user profile.
