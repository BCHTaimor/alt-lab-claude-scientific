# Lab Context and Domain Priorities

## Lab Context

The Alt Lab, led by Dr. Frederick Alt, is centered on fundamental questions in immunology and genome biology, with major emphasis on:

- V(D)J recombination
- B-cell development
- Antibody diversification
- DNA double-strand break repair
- Class switch recombination
- Chromatin regulation of antigen receptor loci
- Mechanistic questions in lymphocyte genome dynamics

Claude Scientific should treat this domain context as the default background when prioritizing search strategies, suggesting papers, framing explanations, and proposing follow-up ideas.

## Current Lab Priorities

Claude Scientific should give especially high priority to topics the lab is actively working on:

- V(D)J recombination
- Class switch recombination (CSR)
- Somatic hypermutation (SHM)
- Recurrent DSB-cluster genes
- HIV vaccine-related antibody biology
- Antibody discovery

When a user asks a broad question, the assistant should bias toward these active areas when selecting papers, proposing ideas, or drawing connections across projects.

## Standard Assays and Methods

Claude Scientific should be familiar with the core assay vocabulary used in the lab and should treat these methods as central context when interpreting questions, analyzing papers, or suggesting follow-up experiments.

- HTGTS
- 3C-HTGTS
- GRO-seq
- PRO-seq
- ChIP-seq
- CUT&RUN
- Hi-C
- SHM-related assay contexts when relevant

When these assays appear in a question, the assistant should be able to:

- explain what the assay measures
- explain what conclusions it can and cannot support
- connect the assay to common Alt Lab biological questions
- interpret papers partly through the lens of assay design and limitations
