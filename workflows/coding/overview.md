# Coding Workflow

Use this workflow for code edits, repository maintenance, testing, Git operations, analysis scripts, reports, and project-file work. Confirm the requested change and any authorization needed for state-changing actions before selecting the skills below.

## Skills

- [Code Workflow Basics](skills/skill-code-workflow-basics.md): Selects the relevant implementation, testing, documentation, and safety skills for a coding task.
- [Project Integrity Boundaries](skills/skill-project-integrity-boundaries.md): Protects existing project behavior, user work, and scope boundaries during changes.
- [Project Collaboration Boundaries](skills/skill-project-collaboration-boundaries.md): Defines how to work safely alongside other contributors and uncommitted changes.
- [Reproducible Analysis Design](skills/skill-reproducible-analysis-design.md): Designs analysis workflows that can be rerun and independently understood.
- [Git Safety and Approval Workflow](skills/skill-git-safety-and-approval-workflow.md): Governs staging, commits, history changes, and other Git actions that require care or approval.
- [Python Contract and Docstring Writing](skills/skill-python-contract-and-docstring-writing.md): Defines explicit inputs, outputs, side effects, and invariants for Python code.
- [Python Extension Patterns](skills/skill-python-extension-patterns.md): Guides safe extension of Python abstractions and integration points.
- [Test Case Design for Public Interfaces](skills/skill-test-case-design-for-public-interfaces.md): Designs meaningful tests around public behavior and relevant partitions.
- [Test Suite Building from Contracts](skills/skill-test-suite-building-from-contracts.md): Builds unit and integration tests from documented behavior and invariants.
- [Bash Test Design for File-Based Pipelines](skills/skill-bash-test-design-for-file-based-pipelines.md): Tests shell pipelines, fixtures, generated files, and exit-code behavior.
- [Repository Structure and Testing Layout](skills/skill-repo-structure-and-testing-layout.md): Organizes entry points, modules, tests, and fixtures into navigable locations.
- [Repository Structure and File Placement](skills/skill-repo-structure-and-file-placement.md): Places source, configuration, documentation, and generated artifacts predictably.
- [README Writing for Technical Projects](skills/skill-readme-writing-for-technical-projects.md): Documents purpose, inputs, outputs, commands, and verification for technical projects.
- [Agent-Ready Document Writing](skills/skill-agent-ready-document-writing.md): Creates standalone instructions that remain usable in future work sessions.
- [Analysis Report Writing](skills/skill-analysis-report-writing.md): Structures analysis reports around questions, methods, results, and limitations.
- [Report Version Preservation](skills/skill-report-version-preservation.md): Preserves prior report versions while creating clear, traceable updates.
- [File Naming and Versioning](skills/skill-file-naming-and-versioning.md): Establishes predictable names and version labels for project artifacts.
- [Workflow Documentation and Command Logging](skills/skill-workflow-documentation-and-command-logging.md): Records reproducible workflow steps and commands when logging is authorized.
- [Output File Discipline](skills/skill-output-file-discipline.md): Prevents accidental overwrites and keeps generated outputs explicit.
- [Output Directory Organization](skills/skill-output-directory-organization.md): Keeps generated outputs separated, structured, and easy to inspect.
- [Original Data Protection](skills/skill-original-data-protection.md): Protects original and sensitive data from destructive or unsafe handling.
- [Language and Tool Selection](skills/skill-language-and-tool-selection.md): Chooses implementation languages and tools based on task requirements and maintenance needs.

## Workflow

1. Select only the skills relevant to the task.
2. Inspect the relevant project context before changing files.
3. Implement the requested work while preserving existing user changes.
4. Verify the result in proportion to the risk and report what changed and was tested.
