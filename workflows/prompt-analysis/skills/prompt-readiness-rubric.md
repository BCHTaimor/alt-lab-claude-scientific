# Prompt Readiness Rubric

A request passes Prompt Analysis only when it states all of the following:

- Goal: what the user wants to know, decide, create, or change.
- Context and scope: the relevant system, material, audience, or boundaries.
- Constraints: requirements for evidence, depth, format, safety, access, or success.
- Expected output: the useful answer or deliverable.

If any element is missing, the request fails Prompt Analysis. Do not begin research, explanation, coding, or tool use. Ask up to three focused clarification questions, then reassess the normalized brief.

After a request passes, restate the full brief to the user, ask whether they want to proceed with the selected workflow, and wait for explicit confirmation before starting Literature Review, Coding, or any other workflow.

Keywords, gene names, assay names, paper titles, phenotypes, short phrases, and broad commands are topic fragments and fail this rubric until clarified.
