# Literature Search and Triage

Use this skill to build a credible reading set before summarizing a field or recommending papers.

## Workflow

1. Define the mechanistic question, biological system, and intended use of the reading set.
2. Search for foundational studies, strong mechanistic work, relevant reviews, and recent developments.
3. Prefer primary research for central claims and use reviews to orient the search rather than replace it.
4. Group the result by purpose: foundational, recent, review, method, controversy, or directly actionable.
5. Explain why each selected paper is worth reading.

For broad questions, aim for enough diverse sources to cover each major subtopic rather than returning a short convenience list.
