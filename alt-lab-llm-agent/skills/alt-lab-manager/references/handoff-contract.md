# Manager-to-Specialist Handoff Contract

Every delegated task should include only the context needed to complete the assigned lane.

## Required handoff fields

```text
Goal:
Context and scope:
Constraints:
Expected output:
Relevant sources or files:
Authorization boundary:
```

## Specialist return fields

```text
Bottom line:
Evidence or files examined:
Findings:
Uncertainty or limitations:
Actions performed:
Recommended next step:
```

The manager remains responsible for resolving conflicts between specialist outputs, requesting user decisions, and producing the final answer. Specialists must not expand their lane or infer authority for unrelated actions.
