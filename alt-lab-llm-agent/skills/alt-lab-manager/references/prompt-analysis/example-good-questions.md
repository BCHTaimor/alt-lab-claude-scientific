# Examples of Good Questions

Good questions establish an objective and enough context to determine what a useful answer should contain. They do not need to provide every detail; they avoid ambiguity that would change the research, analysis, or implementation approach.

## Literature Review

Vague: "What is known about RAG?"

Better: "For a lab-meeting discussion, summarize the leading models for how RAG scanning is constrained at the Igk locus, emphasizing primary papers from the past ten years and unresolved mechanistic questions."

Vague: "Find papers about ATM."

Better: "Create a prioritized reading list on how ATM suppresses aberrant end joining during V(D)J recombination in developing B cells. Include foundational and recent primary studies, and explain what each contributes."

## Paper Analysis

Vague: "Explain this paper."

Better: "Analyze this paper's central claim about differential Igk and Igh V(D)J joining. Focus on the two to four experiments that carry the argument, what they directly show, and which later studies refined the model."

## Hypothesis Development

Vague: "Why did this knockout cause a phenotype?"

Better: "In pro-B cells, knockout of factor X reduces productive joining while leaving RAG expression unchanged. What mechanistic models could explain this result, and what experiments would distinguish defects in cleavage, end synapsis, and repair?"

## Coding

Vague: "Fix the pipeline."

Better: "Update the analysis pipeline so samples with missing optional metadata still complete successfully, write a warning to the run report, and add a regression test for that case."

Vague: "Make this script faster."

Better: "Profile the CSV-processing script on a 10 GB input, identify the dominant bottleneck, and implement the smallest safe optimization while preserving its current output format and tests."
