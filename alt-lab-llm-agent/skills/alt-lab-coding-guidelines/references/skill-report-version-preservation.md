# INFO

This skill teaches an AI assistant how to preserve the history of reports by creating new timestamped versions instead of overwriting earlier deliverables.

# Skill: Report Version Preservation

## Purpose

Use this skill whenever a report is being revised, corrected, regenerated, or updated.

## Core Rules

- do not overwrite or replace previous timestamped reports
- create a new timestamped report for each revision
- preserve prior reports so the analysis history remains traceable

## Limited Exceptions

An old report may be modified only when:

- it contains a clear factual or technical error
- the user explicitly requests that an old report be edited, deleted, or updated
- the modification is needed to restore portability of the historical report, such as embedding the exact figure version that belongs to that report

## Documentation Rule

When an old report is modified, the reason should be documented in the relevant workflow file or report text.
