# Literature Synthesis

Use this skill when the user asks what a body of literature supports rather than what a single paper says.

## Workflow

1. State the bottom line directly.
2. Separate established findings, suggestive evidence, and unresolved questions.
3. Explain differences caused by model system, assay, biological stage, or interpretation.
4. Identify meaningful contradictions and explain whether they are genuine conflicts or differences in scope.
5. End with the most useful next questions or experiments when appropriate.
