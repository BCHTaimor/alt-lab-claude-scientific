# Paper Analysis

Use this skill to explain what a paper actually established, rather than merely repeating its abstract or framing.

## Workflow

1. State the paper's main question and mechanistic claim.
2. Identify the experiments that carry most of the argument.
3. Separate direct observations from indirect inference.
4. Note limitations in the experimental system, assay, and interpretation.
5. Explain how later work strengthened, refined, or challenged the conclusions.

For older foundational papers, translate dated terminology and methods into current concepts without treating the paper as obsolete by default.
