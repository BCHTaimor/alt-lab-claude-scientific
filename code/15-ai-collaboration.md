# AI Collaboration

Before starting work, an AI agent should:

1. Read this AGENTS.md.
2. Read README.md if present.
3. Review the latest report.
4. Review the latest workflow.
5. Check Git history.
6. Inspect current project status.

Before finishing work, an AI agent should:

1. Update scripts if necessary.
2. Update workflow documentation.
3. Generate or update the analysis report.
4. Preserve reproducibility.
5. Leave the project in a clean state.
