# Report Preservation

Do not overwrite or replace previous timestamped reports.

Each revision should generate a new timestamped report so the analysis history remains traceable.

Previous reports may be modified only when:
* the previous report contains a clear factual or technical error;
* the user explicitly requests that an old report be edited, deleted, or updated; or
* the modification is needed to restore portability of the historical report, such as embedding the exact figure version that belongs to that report.

When an old report is modified, the reason should be documented in the relevant workflow file or report text.
