# Standard Project Structure

A typical project should be organized as follows.

```text
Project/

├── AGENTS.md
├── README.md
├── original/
├── input/
├── scripts/
├── output/
├── work_flows/
├── reports/
├── docs/
└── .git/
```

Directory purposes:

## original/

Contains immutable original files.

Examples:

* raw sequencing data
* downloaded databases
* published supplementary files
* original spreadsheets

Rules:

* NEVER edit.
* NEVER rename.
* NEVER delete.
* If processing is needed, copy files into `input/` or create symbolic links.

---

## input/

Contains analysis input files.

Examples:

* copied data
* symbolic links to individual large files
* intermediate files prepared for analysis

Large files should preferably be symbolic links rather than duplicated.

Rules:

* Symbolic links in `input/` should point to files, not directories.
* Do not hide required input inventory behind directory-level symbolic links.
* If many raw files are required, create explicit per-file symbolic links or a documented input manifest that lists every required source file.
* The workflow file must make clear which `input/` files are used and where each linked file originates.

---

## scripts/

Contains all analysis scripts.

Rules:

* Put analysis scripts directly under `scripts/`.
* Do not create date-based subdirectories under `scripts/`.
* Use date suffixes in filenames instead of date folders.
* Non-date subdirectories are allowed only for reusable modules, libraries, or packaged helper code when they reduce real complexity.

Typical languages:

* R
* Perl
* Python
* Bash

R is preferred for:

* statistics
* visualization
* publication-quality figures

Perl and/or Python are preferred for:

* parsing
* large-scale data processing
* file conversion

---

## output/

Contains analysis results.

Examples:

* TSV
* CSV
* TXT
* PDF
* PNG
* SVG
* HTML generated by scripts

Do not manually edit output files.

---

## work_flows/

Contains reproducible workflow descriptions.

Each workflow should completely reproduce one analysis.

---

## reports/

Contains human-readable analysis reports.

Reports summarize the complete analysis.
