# INFO

This skill teaches an AI assistant how to choose practical languages and tools based on the task rather than habit, novelty, or unnecessary abstraction.

# Skill: Language And Tool Selection

## Purpose

Use this skill when deciding which implementation language or tool is most appropriate for a coding task.

## Preferred Choices

### Statistics

Prefer `R`.

### Visualization

Prefer `ggplot2`.

### Large-Scale Parsing

Prefer `Perl` or `Python`.

### General Scripting

Prefer `Bash`.

## Additional Guidance

- code should be readable
- code should be modular
- comments should clarify non-obvious behavior
- avoid unnecessary dependencies when simpler tools are sufficient
